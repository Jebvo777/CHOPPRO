# ЧОППРО — портал с автоматическим обновлением из GitHub

Готовый архив содержит портал на PHP 8.3+ без Laravel и без Composer. GitHub Jebvo777/CHOPPRO — источник разделов, текстов, требований, сценариев, чек-листов, OpenAPI, диаграмм, прототипов и состава поставки.

## Установка один раз

1. Распакуйте содержимое архива в каталог текущего портала с заменой файлов. Для чистой установки используйте пустой каталог. Старые локальные документы, прототипы и ZIP не используются новым меню; их можно убрать после проверки.
2. Хостинг должен выполнять PHP 8.3+, иметь доступ по HTTPS к api.github.com и raw.githubusercontent.com и разрешать запись в каталог `storage/`. cURL ускоряет скачивание; без него используется HTTPS через PHP streams (allow_url_fopen + OpenSSL).
3. Откройте сайт. Настройки уже указывают на правильный репозиторий; публичный GitHub работает без токена.

До слияния PR № 2 с основной веткой автоматически используется ветка portal/github-auto-sync. После слияния портал сам перейдет на default branch GitHub; менять архив или настройки сайта не потребуется.

На Apache применяются вложенные .htaccess. На Nginx используйте `deploy/nginx.conf`, включая PATH_INFO для prototype.php и запрет доступа к app, bootstrap, storage, tests, bin, deploy и config.php. Кэш также можно вынести за web-root через CHOPPRO_CACHE_DIR.

## Как обновляется содержимое

- Новые/измененные/удаленные документы и вложения в `docs/` подхватываются автоматически. Подпапки docs получают собственные разделы меню.
- Основное меню, порядок разделов, описания, имя, стек, состояние проекта и дополнительные источники задаются в `acceptance-portal/portal.json` в GitHub. В интерфейсе не зашито ограничение Этапом 1.
- Матрица читается из `docs/Матрица_требований_ЧОППРО.csv`; сценарии и приемка читаются прямо из соответствующих Markdown-документов. Дублирующие локальные PHP/JSON/HTML-копии этих текстов не используются.
- PUML автоматически преобразуется в SVG/PNG GitHub Actions. Портал показывает картинку только когда ее source_sha совпадает с актуальным PUML. Между исходным коммитом и коммитом рендеров показывается исходник, без устаревшей картинки.
- HTML/CSS/JS прототипов и все относительные ресурсы берутся из одного коммита. Их JavaScript работает в изолированном iframe; скачанный PHP никогда не запускается.
- Поставка скачивается из конкретного показанного коммита GitHub; старые фиксированные ZIP заменены.

Проверка без токена выполняется максимум раз в 5 минут, с токеном — раз в минуту. Обращение посетителя запускает проверку; постоянно открытая вкладка тоже проверяет версию каждую минуту. При новом коммите появляется ссылка «Открыть актуальную» — так ввод пользователя не теряется. При следующем открытии страницы показывается новый комплект.

Перед публикацией комплект скачивается и проверяется по Git blob SHA целиком. При сбое/лимите запросов остается последний целостный комплект с датой и предупреждением. Это не обещание обновления во время отсутствия связи. Кэш хранит десять последних комплектов и автоматически удаляет лишние файлы. Резервный комплект в архиве работает до первой успешной синхронизации.

## Необязательные настройки сервера

- `CHOPPRO_GITHUB_TOKEN` — GitHub fine-grained token с Contents: read для CHOPPRO; только в окружении PHP, никогда в браузере или архиве. Поддерживается также GITHUB_TOKEN.
- `CHOPPRO_SYNC_INTERVAL` — интервал проверки в секундах, минимум 60.
- `CHOPPRO_GITHUB_BRANCH` — фиксированная ветка. По умолчанию отслеживается default branch репозитория.
- `CHOPPRO_CACHE_DIR` — абсолютный путь к writable-кэшу.

Кэш: до 2000 выбранных файлов, 10 MiB на файл, 60 MiB на комплект. Если материалы вырастут сверх этих лимитов, увеличьте лимиты в config.php под возможности хостинга.

Если обновление должно идти без посетителей, необязательный cron: `*/5 * * * * /usr/bin/php /var/www/choppro-portal/bin/sync.php`. Ручное форсирование для диагностики: `php bin/sync.php --force`.

## Новые разделы без обновления портала

Поддерживаются типы overview, docs, diagrams, prototypes, stories, requirements, file, github, acceptance, delivery, directory. Для любого нового раздела добавьте запись в sections у portal.json. Пути — относительно корня репозитория. Новый исполняемый код интерфейса по-прежнему требует обычной установки новой версии портала; содержимое и разделы перечисленных типов обновляются автоматически.

## Проверка и сборка

`php acceptance-portal/tests/run.php` — тесты обновления, удаления/добавления материалов, изоляции, ETag, лимитов, сбоев и целостности. `python3 acceptance-portal/bin/build_bundle.py --output dist/CHOPPRO_portal_github_auto.zip` — готовый ZIP из Git-репозитория. GitHub Actions проверяет PHP, рендерит страницы, проверяет браузерные сценарии и прикладывает архив к запуску CI.

Осознанные решения: Laravel не используется; Figma исключена; PWA заменена самостоятельными Android/iOS-приложениями.
