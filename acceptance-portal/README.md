# Портал приемки Этапа 1

Автономный PHP-портал подготовлен для публикации на m20.system404-design.ru.

Портал содержит обзор проекта, онлайн-просмотр документации, диаграммы PUML/SVG/PNG, OpenAPI, матрицу требований, live/snapshot статус GitHub, кликабельные low-fidelity прототипы и сценарии UC-01…UC-05, а также интерактивный чек-лист приемки с сохранением отметок в браузере.

Полный deployable-пакет портала поставляется отдельным ZIP-архивом, поскольку в него входят сгенерированные HTML/DOCX, PNG/SVG и скачиваемые архивы исходников. Для работы портала база данных не требуется.

После подготовки финального UI/UX достаточно указать ссылку Figma в data/project.php и пройти соответствующий пункт чек-листа.

Важно: фактический backend-стек — чистый PHP без Laravel. Текущая договорная редакция содержит PHP/Laravel, поэтому до окончательной приемки Этапа 1 требуется письменное согласование этой замены.
