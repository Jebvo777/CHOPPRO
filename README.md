# ЧОППРО

Система управления охраной: PHP 8.3/PDO, MySQL 8, рабочие кабинеты администратора ЧОП, заказчика и платформы, биржа труда и общий мобильный проект React Native + Expo + TypeScript для Android и iOS. Laravel не используется.

Портал, приложения, документация и миграции получают актуальную версию из `main`. Новый выпуск включается после успешных проверок; файлы загружаются в отдельный каталог и работающий запрос сохраняет свою версию. При открытии обновлённого портала миграции применяются автоматически, затем переключается демо. В панели управления дополнительный пароль не требуется. Кнопки «Обновить систему» и «Актуализировать БД» позволяют повторить обработку; существующие записи не заменяются тестовыми.

## Рабочие приложения

| Приложение | Возможности |
|---|---|
| Администратор | Команда, документы, договоры, объекты и геозоны, график, назначения, присутствие, визуальный конструктор обходов, рассмотрение происшествий, табели, PDF/XLSX/CSV и черновики ежемесячных отчётов |
| Сотрудник · Android / iOS | Свои смены и инструкции, QR и GPS, начало и завершение работы, обходы, происшествия с фото/аудио и восстановление зашифрованной очереди после перезапуска |
| Заказчик | Собственные объекты, фактическое покрытие постов, опубликованные происшествия и материалы, неизменяемые версии отчётов, PDF и ознакомление |
| Платформа | Организации, модули и ограничения ресурсов, состояние обработчика, карантин, аудит и временный доступ поддержки |
| Биржа труда | Поиск, карточки вакансий, ручной закреп №1–3 и отклик работодателю |

Интерфейсы содержат глобальный поиск, избранное и недавние карточки, именованные фильтры, библиотеку PDF, воронку кандидатов с переносом и отменой, недельный планировщик и визуальный конструктор графика. Связанные записи доступны из карточек; графики и показатели используют данные организации. Все названия полей — на русском. Карта Яндекса работает через официальный виджет без ключа API: точка объекта выбирается на карте, геозона задаётся кругом или вершинами полигона.

## Данные и доступ

Изоляция организаций и объектов проверяется сервером. Поддержка открывается с причиной на 1–30 минут и отражается в аудите. Ограничения пользователей, сотрудников, объектов и хранилища применяются при создании данных и загрузке файлов. Документы хранятся приватно; новый файл остаётся в карантине до проверки сканером.

Присутствие проверяет GPS, геозону, точность, QR, опубликованное назначение и время. Повторная доставка одного события не создаёт дубликат. Корректное заступление обновляет фактическое покрытие и состояние смены; завершение фиксирует отработанное время. Спорное событие учитывается после отдельного ручного решения.

Срок хранения — **3 года**. Исторические отметки, аудит и опубликованные отчёты очищаются по возрасту; документы — после окончания срока или удаления; договоры — после окончания услуг; деактивированные персональные данные — после деактивации. Действующие документы, договоры и незавершённые процессы сохраняются. Очистка включает приватные файлы и журнал результата; неудачное удаление файла повторяется.

**Внешние уведомления, SMS, почта, распознавание речи и другие внешние интеграции исключены из текущей поставки.** Внутренние действия, пересчёт сроков и очередь отчётов работают. В демо охранник входит по тестовому коду; в рабочем режиме доставка OTP требует выбранного провайдера. Платный аукцион закрепа не включён.

## Проверка

Тестовые данные: 5 организаций, 1000 сотрудников, 3000 текстовых PDF-документов, 320 кандидатов, 120 объектов, 360 постов, 10080 смен, 80 вакансий и связанные операционные записи. Данные синтетические.

Мобильное демо: телефон `+79000000007`, тестовый код отображается при входе.

Для веб-демо: `admin@obereg.example`, `customer@obereg.example`, `platform@choppro.example`; пароль `Demo2026!`. Второй фактор тестового аккаунта подставляется в демо. Это авторизация приложения; панель обновлений портала открывается без пароля.
