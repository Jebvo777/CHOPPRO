# ЧОППРО

Репозиторий программного комплекса ЧОППРО (MVP).

## Технологический стек

- Backend: PHP 8.3+ без фреймворка.
- База данных: MySQL 8.
- Кэш и фоновые очереди: Redis.
- Мобильные приложения: React Native с отдельными сборками Android и iOS.
- Веб-интерфейсы: PHP, HTML, CSS, JavaScript.
- API: REST JSON, версия `/api/v1`.

## Состав репозитория

- `backend/` - серверная часть и REST API.
- `web/` - каркас административной панели и кабинета заказчика.
- `mobile/` - каркас React Native приложения охранника.
- `prototypes/` - интерактивные прототипы основных пользовательских сценариев.
- `docs/` - документация Этапа 1 и диаграммы.
- `docker/` - окружение PHP для локальной разработки и staging.
- `.github/workflows/` - автоматические проверки репозитория.

## Быстрый запуск

1. Скопировать `.env.example` в `.env`.
2. Выполнить `docker compose up -d --build`.
3. Выполнить миграции: `docker compose exec app php backend/scripts/migrate.php`.
4. Проверить API: `http://localhost:8080/api/v1/health`.
5. Открыть прототипы: `prototypes/index.html`.

## Правила ветвления

- `main` - стабильная версия.
- `develop` - интеграционная ветка разработки.
- `feature/<задача>` - функциональные изменения.
- `fix/<задача>` - исправления.

Слияние в `main` выполняется после прохождения проверок и приемки соответствующего этапа.
