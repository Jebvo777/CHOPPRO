# ЧОППРО

Репозиторий MVP программного комплекса ЧОППРО.

## Технологический стек

- Backend: PHP 8.3+ без Laravel и без серверного фреймворка.
- База данных: MySQL 8 / InnoDB / utf8mb4.
- Redis: кэш, rate limit, очереди и временные данные.
- Мобильные приложения: React Native с отдельными Android и iOS сборками.
- Web: PHP, HTML, CSS, JavaScript.
- API: REST JSON /api/v1.
- Файлы: S3-совместимое хранилище.

Важно: текущая договорная редакция ранее указывала Laravel. Переход на чистый PHP зафиксирован как проектное решение и должен быть письменно согласован заказчиком до окончательной приемки Этапа 1.

## Этап 1

В репозитории находятся архитектура, детализированное ТЗ, целевая модель данных, API-контракт, интеграции, матрица требований, реестр отклонений/вопросов, прототипы, PUML-диаграммы, базовый PHP/MySQL/Redis каркас, Docker dev-контур, CI и портал приемки.

## Быстрый запуск backend dev-каркаса

1. Скопировать .env.example в .env.
2. docker compose up -d --build
3. docker compose exec app php backend/scripts/migrate.php
4. Открыть http://localhost:8080/api/v1/health

## Портал приемки

Каталог acceptance-portal содержит автономное PHP-приложение для публикации документации, диаграмм, матрицы требований, GitHub-статуса, кликабельных прототипов и чек-листа приемки. Он рассчитан на обычный PHP-хостинг и не требует базы данных.

## Ветки

- main - стабильная поставка.
- develop - интеграционная ветка.
- feature/* - функциональные изменения.
- fix/* - исправления.
