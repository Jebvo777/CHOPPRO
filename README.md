# ЧОППРО

Репозиторий MVP программного комплекса ЧОППРО.

## Этап 1

В репозитории зафиксированы требования и границы MVP, архитектура, модель данных, API-контракт, схема интеграций, модель ролей и доступа, матрица требований, пользовательские сценарии, прототипы, диаграммы, базовый backend-каркас, миграции MySQL и CI/CD.

## Технологический стек

- Backend: PHP 8.3+.
- База данных: MySQL 8 / InnoDB / utf8mb4.
- Redis: кэш, rate limit, очереди и временные данные.
- Мобильные приложения: React Native с отдельными Android и iOS сборками.
- Web: PHP, HTML, CSS, JavaScript.
- API: REST JSON /api/v1.
- Файлы: S3-совместимое хранилище.

## Структура репозитория

- `backend/` — серверная часть, REST API, миграции и тестовый каркас.
- `web/` — административный и клиентский web-контуры.
- `mobile/` — структура мобильных приложений Android/iOS.
- `prototypes/` — прототипы основных пользовательских сценариев.
- `docs/` — архитектура, модели, спецификации, матрицы и диаграммы.
- `.github/workflows/` — CI/CD конфигурация.
