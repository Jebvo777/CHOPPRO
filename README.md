# ЧОППРО

Репозиторий MVP программного комплекса ЧОППРО.

## Этап 1

В репозитории зафиксированы требования и границы MVP, архитектура, модель данных, API-контракт, схема интеграций, модель ролей и доступа, матрица требований, пользовательские сценарии, прототипы, диаграммы, базовый backend-каркас, миграции MySQL и CI/CD.

Этап 1 завершен. Материалы Этапа 1 являются исходной проектной базой для реализации Core MVP.

## Технологический стек

- Backend: PHP 8.3+ / PDO, модульный монолит; Laravel не используется.
- База данных: MySQL 8 / InnoDB / utf8mb4.
- Redis: кэш, rate limit, очереди и временные данные.
- Мобильный контур: отдельные полноценные приложения для Android и iOS.
- Web: PHP, HTML, CSS, JavaScript.
- API: REST JSON /api/v1.
- Файлы: S3-совместимое хранилище.

## Структура репозитория

- `backend/` — серверная часть, REST API, миграции и тестовый каркас.
- `web/` — административный и клиентский web-контуры.
- `mobile/` — структура мобильных приложений Android/iOS.
- `prototypes/` — прототипы основных пользовательских сценариев.
- `docs/` — архитектура, модели, спецификации, матрицы и диаграммы.
- `acceptance-portal/` — портал, автоматически синхронизирующийся с GitHub.
- `.github/workflows/` — CI/CD конфигурация.

## Актуализация Core MVP

Начиная с Этапа 2 Git-репозиторий, OpenAPI и миграции базы данных актуализируются по мере реализации Core MVP и должны соответствовать фактически реализованному функционалу.

## Автоматический портал проекта

Портал получает разделы, документы, матрицу требований, сценарии, чек-лист приемки, OpenAPI и прототипы из текущего коммита GitHub. Настройки отображения: `acceptance-portal/portal.json`. Новые документы и папки в `docs/` обнаруживаются автоматически. Редактировать размещенную копию портала для обновления содержимого не требуется.

UI/UX поставляется интерактивными HTML/CSS/JS-прототипами; Figma исключена. Мобильный контур — отдельные React Native приложения Android/iOS; PWA исключена.

Сборка архива: `python3 acceptance-portal/bin/build_bundle.py --output dist/CHOPPRO_portal_github_auto.zip`. Инструкция: `acceptance-portal/README.md`.
