# Прототипы Этапа 1

Прототипы фиксируют структуру экранов, навигацию, состояния и основные пользовательские цепочки.

Покрываются четыре контура: Admin, Mobile Android/iOS, Client и Platform.

Ключевые пользовательские сценарии:

- UC-01 Подключение ЧОПа.
- UC-02 Заступление на смену.
- UC-03 Офлайн check-in.
- UC-04 Происшествие.
- UC-05 Ежемесячный отчет заказчику.

Дополнительно отражены сценарии обхода, контроля документов, tenant/RBAC, ручной проверки attendance и подтверждения отчета.
