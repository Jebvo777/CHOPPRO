# Кликабельные прототипы Этапа 1

Прототипы являются low-fidelity и предназначены для подтверждения структуры, навигации, состояний и пользовательских цепочек. Финальный визуальный UI/UX выполняется отдельно в Figma.

Покрываются четыре контура: Admin, Mobile Android/iOS, Client и Platform. Минимальный набор экранов соответствует договорной редакции ТЗ.

В deployable-портале приемки подготовлены пошаговые кликабельные сценарии:
- UC-01 Подключение ЧОПа.
- UC-02 Заступление на смену.
- UC-03 Офлайн check-in.
- UC-04 Происшествие.
- UC-05 Ежемесячный отчет заказчику.

Дополнительно подготовлены цепочки обхода, истечения документа, tenant/RBAC, ручной проверки attendance и подтверждения отчета.
