# UI/UX прототипы ЧОППРО

Интерактивные HTML/CSS/JS-макеты фиксируют визуальную систему, структуру экранов, навигацию, основные состояния и ключевые пользовательские сценарии ЧОППРО.

Прототип выполнен в светлой теме и использует единую дизайн-систему: сетку, типографику, цветовые роли, карточки, таблицы, статусы, формы, навигацию и иконографику.

Представлены четыре контура:

- Admin / ЧОП — управление организацией, сотрудниками, документами, заказчиками, объектами, постами, графиками, сменами, attendance, обходами, происшествиями, отчетами, аудитом и настройками.
- Mobile / Охранник — Android/iOS сценарии OTP, смены, инструкции, check-in/out, QR, геолокации, обходов, происшествий, offline queue, уведомлений и профиля.
- Кабинет заказчика — объекты, покрытие постов, опубликованные происшествия, отчеты и подтверждение ознакомления.
- Platform — tenants, тарифы и лимиты, feature flags, health, версии контента и break-glass audit.

Карта прототипа объединяет 63 экрана и позволяет переходить между ними через боковую навигацию и глобальный поиск.
