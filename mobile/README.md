# Мобильное приложение охранника

Каркас отдельного мобильного приложения ЧОППРО на React Native для Android и iOS.

На Этапе 1 зафиксированы структура экранов, навигационные сценарии, слой API, локальное хранилище и требования к офлайн-очереди. Реализация рабочих сценариев check-in/out, QR, геолокации, обходов, происшествий и синхронизации выполняется на Этапе 3.
