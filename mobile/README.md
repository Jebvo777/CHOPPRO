# ЧОППРО — мобильное приложение

Единый проект React Native, Expo и TypeScript для Android и iOS. Рабочие сценарии охранника: смены, инструкции, QR, геолокация, отметки, обходы, происшествия, вложения и синхронизация сохранённых событий.

Сервер — существующий PHP API проекта. Уведомления и внешние сервисы не подключаются. Геолокация запрашивается только при рабочих действиях. Платформенные проекты генерируются из общей конфигурации; проверка и архивы собираются в GitHub Actions.
