# Экраны мобильного приложения

Планируемые экраны MVP:

- Авторизация по номеру телефона.
- Подтверждение одноразового кода.
- Главный экран и ближайшая смена.
- Карточка смены и инструкции.
- Check-in/check-out.
- QR-сканер.
- Обход и контрольные точки.
- Создание происшествия с фото и аудио.
- Очередь офлайн-событий и состояние синхронизации.
- Уведомления.
