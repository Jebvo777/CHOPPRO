# Интеграции ЧОППРО · текущий состав

Актуализировано 09.10.2026 по реализованному контуру этапов 2–4. Проектные варианты внешних адаптеров не означают готовое подключение провайдера.

## Внутренний API и мобильная синхронизация

Веб-кабинеты и Android/iOS используют серверный REST JSON `/v1`. Нативный клиент передает Bearer и `X-Choppro-Client: native`, без Cookie/Origin. Снимок данных, события и вложения проходят через `/mobile/snapshot`, `/mobile/events` и `/mobile/upload`. Права организации и объектов проверяются сервером; очередь сохраняет исходное время и устраняет повторы.

## Уведомления и внешние сервисы

По последнему рабочему уточнению доставка уведомлений, включая in-app, SMS/OTP, email, push/Telegram, распознавание речи и прочие внешние интеграции исключены из текущего объема. Обещание подключить эти каналы на этапе 4 больше не является текущим планом. Изменение договорного объема закрепляется [допсоглашением № 3](28_Дополнительное_соглашение_о_выполнении_Этапа_4.md) после подписания. Демонстрационный OTP, внутренние события, контроль сроков и отчетность сохраняются; production-доставка кода потребует отдельного согласования.

## Файлы и антивирус

Рабочие документы, фото, аудио и отчеты находятся в приватной файловой системе; MySQL хранит метаданные и контрольные суммы. Выдача идет через серверную проверку tenant/object scope и разрешения. S3 и signed URL не являются обязательной частью текущей реализации. Новый файл находится в карантине до успешной проверки; реальный сканер и его отказоустойчивость еще необходимо подтвердить в production.

## Карты

Работает официальный iframe-виджет Яндекс Карт без ключа API. Приложение дает выбрать/переместить точку, задать круг или полигон и сохранить координаты. Геозону проверяет сервер. Новая интеграция платного геокодера/API не включена; действующий виджет сохраняется.

## Файловая выгрузка для 1С

Бухгалтерская выгрузка CSV/XLSX реализована и поддерживает сопоставление полей. Формулы экранируются как текст. До финальной приемки нужно получить образец заказчика и проверить импорт в его реальную конфигурацию 1С. Прямой внешний API 1С не включен в текущий объем.

## Фоновые задания и эксплуатация

MySQL хранит внутренние события, rate limit и задания отчетов. PHP worker выполняет контроль сроков/неявок, формирование отчетов и хранение. Redis не требуется. Зашифрованные копии БД/файлов и восстановление реализованы; отдельное место хранения, cron без посетителей, реальный объем и RPO/RTO подтверждаются завершающими проверками этапа 4.
