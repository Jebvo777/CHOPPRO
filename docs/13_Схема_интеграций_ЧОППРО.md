# Схема интеграций ЧОППРО

## 1. Принцип

Внешние сервисы подключаются через внутренние адаптеры. Бизнес-логика не зависит от конкретного SMS, email, Telegram, push, картографического или S3-провайдера. Конкретный production-провайдер и его учетные данные на Этапе 1 не фиксируются, если заказчик их не предоставил.

## 2. SMS/OTP

Назначение: OTP охранника и при необходимости критические уведомления. Интерфейс адаптера: отправка сообщения, получение идентификатора провайдера, проверка статуса доставки. Ограничения: rate limit, дедупликация, отсутствие лишних персональных данных.

## 3. Email, Telegram/Web Push и mobile push

Для операционных уведомлений применяется единая очередь. Внешние каналы получают минимальный текст и авторизованную ссылку. Координаты, документы, фото, аудио и подробное описание происшествия во внешний текст не включаются. Mobile push используется для Android/iOS приложения; провайдер определяется при настройке сборок и аккаунтов.

## 4. S3-совместимое хранилище

Хранит документы, фото, аудио, отчеты и иные бинарные вложения. MySQL хранит метаданные, ключ объекта и права доступа. Выдача выполняется через короткоживущий signed URL после серверной проверки tenant и permission. Непроверенные файлы размещаются в отдельном quarantine-контуре.

## 5. Антивирус

После загрузки файл закрыт для пользователей до завершения проверки. Адаптер возвращает CLEAN, INFECTED, ERROR. При INFECTED файл остается изолированным и не выдается по API.

## 6. Карты и геокодер

Используются для адреса, точки и геозоны. Провайдер должен быть доступен для эксплуатации в РФ. Ключи хранятся в secrets, а не в исходном коде.

## 7. 1С

В MVP используется файловый обмен XLSX/CSV по согласованному шаблону. Прямой API-обмен с 1С не входит в MVP. Значения, начинающиеся с =, +, - или @, экранируются как текст.

## 8. Интеграционный outbox

Доменное событие и outbox-запись создаются в одной транзакции MySQL. Фоновый worker доставляет событие адаптеру с повтором и дедупликацией. Такой подход применяется для уведомлений, отчетов и внешних доставок.
