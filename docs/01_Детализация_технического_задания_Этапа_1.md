# Детализация технического задания Этапа 1

## 1. Цель

Зафиксировать техническую основу ЧОППРО до начала реализации Core MVP и исключить неоднозначность по границам MVP, стеку, архитектуре, модели доступа, данным, API и основным пользовательским сценариям.

## 2. Границы MVP

В MVP входят multi-tenant SaaS, административная веб-панель, кабинет заказчика, backend/API и отдельные мобильные приложения охранника Android/iOS. Предусматриваются организации, пользователи, RBAC, сотрудники и документы, compliance, заказчики, объекты, посты, смены, назначения, check-in/out, QR, геолокация, offline sync, обходы, происшествия, уведомления, отчеты, аудит, мониторинг и резервное копирование.

PWA охранника не разрабатывается. Мобильный контур реализуется на React Native с отдельными сборками Android и iOS.

## 3. Технологический стек

Backend - PHP 8.3+ без фреймворка, PDO, подготовленные SQL-запросы и явные транзакции. База - MySQL 8/InnoDB/utf8mb4. Redis - вспомогательная инфраструктура. Mobile - React Native. Web - PHP/HTML/CSS/JavaScript. Файлы - S3-совместимое хранилище.

## 4. Архитектурные принципы

Модульный монолит. Каждая бизнес-сущность tenant содержит `tenant_id`. Tenant определяется из авторизованной сессии. Мобильные повторяемые операции используют `Idempotency-Key`. Серверные временные метки хранятся в UTC. Исторические события не переписываются без необходимости.

## 5. Результаты

Должны быть готовы: стек, модульная архитектура, целевая модель данных, базовая миграция tenant/users/RBAC/audit, API namespace, модель авторизации и object scope, прототипы Admin/Client/Mobile, структура репозитория, Docker Compose и CI.
