# Реестр вопросов, решений и допущений ЧОППРО · 09.10.2026

Реестр отражает актуальную реализацию и условия завершения этапа 4. Исходные проектные допущения сверены с последними рабочими решениями.

| Вопрос | Решение / состояние | Остающееся действие |
|---|---|---|
| Технологии | PHP 8.3/PDO/MySQL, без Laravel; MySQL-очереди, приватные файлы; Redis/S3 не обязательны | Подтвердить production-конфигурацию |
| Мобильные приложения | Android/iOS React Native/Expo/TypeScript 3.0.2; тестовый APK и Simulator переданы | Полевой прогон и подписанные production-сборки |
| Интерфейсы | HTML-прототипы и рабочие приложения; Figma исключена | Итоговая проверка согласованных сценариев |
| Уведомления и интеграции | Включая in-app и SMS/OTP: доставка исключена из текущего рабочего объема; внутренние события сохранены | Подписать уточнение № 3; последующее подключение согласуется отдельно |
| Бухгалтерский шаблон | Файловая выгрузка реализована; фактический образец 1С не подтвержден | Получить образец и оформить контрольный импорт |
| Пилотные объекты | CI использует синтетические данные; реальный полевой протокол отсутствует | Определить устройства/объекты и проверить реальные условия |
| Типы документов и контрольные сроки | Настраиваемые справочники и контроль реализованы | Подтвердить пилотные правила с ответственным заказчика |
| Check-in с фото | Фото не является обязательным условием базовой отметки; фото/аудио реализованы в происшествиях | Изменение основания и сценария check-in согласуется отдельно |
| Данные заказчика | Только свои объекты и разрешенные опубликованные сведения; внутренние данные скрыты | Финальный прогон изоляции и публикаций |
| Хранение | Технические правила трехлетнего хранения и очистка реализованы; действующие процессы сохраняются | Подтвердить договорные/организационные основания и конфигурацию |
| Инфраструктура и ПДн | Production-размещение в РФ, модель угроз/уровень защищенности не подтверждены полным протоколом | Подтвердить размещение и необходимые документы до production |
| Cron, копии и RPO/RTO | Автоматическая проверка копии/восстановления выполнена | Cron без посетителей, отдельное хранение и реальные измерения |
| Безопасность и нагрузка | Tenant/RBAC, аудит, приватность и идемпотентность проверены в CI | Реальный сканер, финальный аудит, нагрузка и отсутствие Critical/High |
| Аккаунты и подпись | Аккаунты магазинов, ключи и профили предоставляются заказчиком по договору | Получить необходимые доступы и проверить production-файлы |
| Биржа и закреп | Ручной топ-3 реализован; денежный аукцион не включен | Для платного повышения требуется отдельное письменное согласование |
| Оплата и сроки | 200 000 рублей / четыре этапа по 50 000; этап 4 оплачивается после завершения и приемки | Итоговый акт и платеж в порядке договора; месячный срок не начинается заново |
| Публикация магазинов | Дополнительные 50 000 рублей по п. 4.11 — за фактическую публикацию обоих приложений | Не смешивать этот результат с подготовкой production-сборок |
