# Состав поставки Этапа 1

В поставку включены документация, исходники PUML, отрендеренные диаграммы в полном архиве, интерактивные HTML-прототипы, формальные DOCX в полном архиве, backend-каркас на чистом PHP, SQL-миграции MySQL, web-каркасы, структура React Native приложения, Docker Compose, CI workflow и OpenAPI-заготовка.

PHP-каркас проверен командой `php -l`; smoke-тест проходит успешно. Формальные DOCX-документы отрендерены и визуально проверены.
