# Критерии приемки Этапа 1

> Исторический материал этапа 1. Текущее состояние этапов 3–4, реальные технологии и оставшиеся условия описаны в [статусе проекта](Статус_проекта_ЧОППРО.md) и [актуальной спецификации](Актуальная_спецификация_ЧОППРО.md). Проектные таблицы, Redis/S3 и внешние адаптеры не означают их наличие в рабочей поставке.

Этап принимается при выполнении следующих условий: детализированы границы MVP и стек; зафиксирована архитектура; определена целевая модель данных; подготовлена базовая SQL-миграция; зафиксирован API-контракт; описаны роли, tenant isolation и object scope; подготовлены прототипы Admin/Client/Mobile; создана структура репозитория; PHP-файлы проходят `php -l`; smoke-тест проходит успешно; Docker Compose содержит PHP/MySQL/Redis; CI выполняет синтаксическую проверку и smoke-тест; переданы документы, исходники PUML и технический каркас.

Команды проверки:

`find backend web -name '*.php' -print0 | xargs -0 -n1 php -l`

`php backend/tests/smoke.php`

`docker compose up -d --build`

`docker compose exec app php backend/scripts/migrate.php`
