# Структура репозитория ЧОППРО

Корень: README, .env.example, .gitignore, .editorconfig, docker-compose.yml.

`backend/public` - front controller. `backend/src/Core` - минимальное ядро. `backend/src/Http` - Router/Request/Response. `backend/src/Database` - MySQL. `backend/src/Middleware` - Auth/Tenant/RBAC. `backend/database/migrations` - SQL-миграции. `backend/tests` - тесты.

`web/admin` - административная панель. `web/client` - кабинет заказчика.

`mobile/src` - navigation, screens, services, storage, types.

`prototypes` - HTML-прототипы. `docs` - документация, OpenAPI и диаграммы. `.github/workflows` - CI.

`acceptance-portal` - PHP-портал приемки с автоматической синхронизацией из GitHub. `portal.json` задает разделы, `bin/build_bundle.py` собирает архив для установки, `bin/render_diagrams.py` обновляет рендеры диаграмм. Рабочая ветка репозитория - `main`.
