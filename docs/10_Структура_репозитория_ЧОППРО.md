# Структура репозитория ЧОППРО · 09.10.2026

Источник проекта — [Jebvo777/CHOPPRO](https://github.com/Jebvo777/CHOPPRO), рабочая ветка `main`. История предыдущих этапов сохраняется.

| Каталог / файл | Назначение |
|---|---|
| `backend/public` | Серверная точка входа API |
| `backend/src/Stage2` | Рабочие доменные модули этапов 2–4, включая Mobile, Reporting, Backup и рассмотрение происшествий |
| `backend/database/stage2` | Рабочие миграции 001–008, индексы и ресурсы демо |
| `backend/database/migrations` | Исходный каркас этапа 1; не заменяет рабочие миграции приложений |
| `backend/tests/stage2`, `backend/tests/stage34` | MySQL-интеграция, доступ, мобильные операции, отчеты, защита и восстановление |
| `web` | Администратор, заказчик, платформа, биржа; общие UI/API-модули |
| `mobile` | React Native / Expo / TypeScript, конфигурация и тесты Android/iOS |
| `acceptance-portal` | Портал документации и приемки этапов 1–4; `portal.json` задает навигацию |
| `host-loader`, `site-release.json` | Проверенное целостное обновление приложений и описание выпуска |
| `prototypes` | Интерактивные HTML-прототипы этапа 1 |
| `docs` | Актуальная спецификация, OpenAPI, матрица, статусы, приемка и исторические материалы |
| `docs/26_…`, `docs/27_…`, `docs/28_…` | Отчеты этапов 3–4 и проект допсоглашения № 3, пары Markdown/Word |
| `tools` | Упаковка, обновление, браузерные, транспортные и нативные проверки |
| `.github/workflows` | Проверки проекта, серверная приемка и сборки мобильных приложений |

Тестовый APK, исходные нативные ZIP и Simulator-комплект опубликованы как артефакты GitHub Actions. [Ссылки и контрольные суммы](Сборки_и_поставка_ЧОППРО.md). Подписанные договорные PDF, production-ключи, пароли инфраструктуры и профили подписи не публикуются.
