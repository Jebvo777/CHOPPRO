# План и чек-лист приемки Этапа 1

## 1. Предмет приемки

Этап 1 подтверждает договорную детализацию требований, архитектуру, модель данных, API-контуры, схему интеграций, прототипы основных Admin/Client/Mobile/Platform сценариев, репозиторий, dev/staging-каркас, базовую структуру PHP/MySQL/Redis и CI/CD.

## 2. Документация

[ ] Детализация ТЗ и границ MVP просмотрена.
[ ] Архитектура и технологический стек подтверждены.
[ ] Замена Laravel на чистый PHP письменно согласована заказчиком.
[ ] Полная модель данных и ERD просмотрены.
[ ] API-контракт и схема ошибок просмотрены.
[ ] Схема интеграций просмотрена.
[ ] Модель ролей, tenant isolation и object scope подтверждены.
[ ] Матрица требований и этапов просмотрена.
[ ] Реестр вопросов/допущений просмотрен.

## 3. Репозиторий и технический каркас

[ ] GitHub-репозиторий доступен заказчику.
[ ] Ветки main и develop существуют.
[ ] Backend-каркас на чистом PHP доступен.
[ ] MySQL core migrations доступны.
[ ] Docker Compose dev-контур описан.
[ ] CI workflow доступен.
[ ] OpenAPI доступен онлайн и как файл.
[ ] Исходники PUML и SVG/PNG-рендеры диаграмм доступны.

## 4. Прототипы

[ ] Admin-контур пройден по основным экранам.
[ ] Mobile Android/iOS контур пройден по основным экранам.
[ ] Client-контур пройден по основным экранам.
[ ] Platform-контур пройден по основным экранам.
[ ] UC-01 Подключение ЧОПа пройден.

[ ] UC-03 Офлайн check-in пройден.

[ ] UI/UX макеты Figma добавлены и согласованы, если требуются заказчиком до закрытия Этапа 1.

## 5. Среда приемки

[ ] Портал приемки опубликован на согласованном staging URL.
[ ] Онлайн-просмотр документации доступен.
[ ] Онлайн-просмотр диаграмм доступен.
[ ] Проверка статуса GitHub работает либо отображается корректный snapshot.
[ ] Кликабельные прототипы открываются без ошибок.

## 6. Завершение

Этап считается подготовленным к подписанию после устранения блокирующих замечаний, письменного согласования отклонения от Laravel и, при необходимости по позиции заказчика, добавления/согласования Figma UI/UX. Интерактивный чек-лист с сохранением отметок в браузере находится в портале приемки.
