# Развёртывание ЧОППРО на новом хостинге

Один комплект устанавливается в `/choppro/` или `/choppro2/`. Браузерные приложения, API, документация и прототипы используют путь, по которому открыт портал. Синхронизация читает `main` репозитория `Jebvo777/CHOPPRO` через HTTPS. Загрузчик проверяет хеши файлов и принимает последующие версии после успешного запуска `Stage 2 acceptance` на соответствующем коммите.

1. В панели хостинга создайте пустую базу `system404_chopro` и назначьте ей прежнего пользователя с прежним паролем. Импортируйте `system404_chopro.sql` через phpMyAdmin или выполните `mysql -u system404_chopro -p system404_chopro < system404_chopro.sql`.
2. Распакуйте архив сайта в выбранный каталог, включая `.htaccess`, `.loader` и `.private`. Для PHP нужны версия 8.3 или новее и расширения `pdo_mysql`, `curl`, `mbstring`, `gd`, `zip` и `openssl`. PHP должен иметь право записи в `.private`. Для Apache должны применяться правила `.htaccess`, а для Nginx настройте запрет прямого HTTP-доступа к `.private` и `.loader`.
3. Перенесите прежний `.private/site.php` в распакованный каталог, если сайт использовал этот файл. Если реквизиты были настроены в панели хостинга, задайте те же `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME` и `DB_PASSWORD` для веб-PHP и PHP CLI. Загрузчик читает `.private/site.php` с приоритетом над переменными окружения.
4. При наличии резервной копии приватных файлов перенесите из прежнего `.private/runtime/` каталоги `uploads`, `reports`, `backups` и файл `key`. Ключ нужен для расшифровки прежних зашифрованных материалов. При первом обновлении на пустом хранилище демонстрационные PDF восстанавливаются по данным БД, если вычисленный SHA-256 совпадает с сохранённым. Для остальных вложений и резервных копий нужны исходные файлы.
5. Откройте `/choppro/` или `/choppro2/`, затем `control.php` в этом же каталоге. Проверьте состояние БД и откройте демо. Для фоновых задач настройте запуск `php /полный/путь/к/сайту/site-cron.php` с теми же реквизитами БД.

Браузерное демо сотрудника соединяется с API того же портала. Для следующей нативной сборки исходники используют `/choppro/` по умолчанию. Если выбран `/choppro2/`, передайте `EXPO_PUBLIC_API_URL=https://system404-extra.ru/choppro2/` при сборке или укажите этот адрес в форме входа.
