# Матрица требований и этапов ЧОППРО · 09.10.2026

Матрица сохраняет **100 требований и 24 сценария AT-01–AT-24** исходного ТЗ. ID, категории, приоритеты и приемочные критерии не заменяются автоматической отметкой о завершении. Историческая колонка `stage1_status` сохранена; текущее состояние находится в новых колонках.

## Актуальный источник

[Матрица CSV](Матрица_требований_ЧОППРО.csv) используется порталом. Поиск работает по тексту, ID и текущему статусу; фильтры — по категории и этапу. Разделение исходной реализации по этапам сохранено. Уведомления и внешние интеграции отмечены как исключенные из текущего рабочего объема, а не как выполненные.

| Колонка | Значение |
|---|---|
| `current_status` | Факт реализации, частичный результат, неподтвержденное условие либо рабочее исключение |
| `verification_status` | Какой уровень проверки подтвержден: автоматический контур, физическое устройство, production или отсутствие подтверждения |
| `scope_note` | Уточнение объема; исключение из договорного Must-состава требует подписанного основания |
| `evidence` | Реализующий модуль/тест и контрольный запуск CI |
| `remaining` | Что еще требуется для полного подтверждения исходного критерия |
| `updated_at` | Дата сверки 2026-10-09 |

## Как читать статусы

«Реализовано в тестовом контуре» означает наличие рабочего кода и подтверждение соответствующим автоматическим сценарием; это не подпись заказчика и не гарантия прохождения всего исходного критерия. «Частично» указывает на непроверенную часть требования. «Требует подтверждения» используется для production, правовых/организационных документов и реальных эксплуатационных измерений. Статус AT описывает доказательство и остаток; итоговый акт пока не оформлен.

Текущая технологическая реализация: PHP/PDO/MySQL, React Native/Expo, приватная файловая система и MySQL-очереди. Хранение — три года с правилами категорий. Изменения по каналам уведомлений, внешним интеграциям и иным договорным условиям действуют после подписания соответствующих соглашений.
