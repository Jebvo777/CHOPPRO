# Реестр архитектурных решений ЧОППРО · 09.10.2026

Номера ранее принятых решений сохранены; уточнения отражают текущую реализацию этапов 2–4.

| Решение | Текущий результат |
|---|---|
| ADR-001 | Backend PHP 8.3 / PDO, без Laravel |
| ADR-002 | MySQL 8 / InnoDB / utf8mb4 — основное транзакционное хранилище |
| ADR-003 | Отдельные Android/iOS-приложения из общего проекта React Native / Expo / TypeScript; мобильная версия 3.0.2 |
| ADR-004 | Модульный монолит; микросервисы требуют измеренного основания |
| ADR-005 | REST JSON `/v1`; OpenAPI 3.0.1. Прежний проектный путь `/api/v1` не является базовым путем рабочего API |
| ADR-006 | Tenant определяется доверенной серверной сессией или токеном |
| ADR-007 | RBAC проверяет разрешения и область объектов, включая файлы и выгрузки |
| ADR-008 | Повторяемые мобильные операции идемпотентны; исходное время устройства сохраняется |
| ADR-009 | Исходные события сохраняются; ручное решение и новая публикация имеют отдельную историю |
| ADR-010 | Очереди, rate limit и внутренние события реализованы в MySQL; Redis не требуется текущей поставке |
| ADR-011 | Бинарные файлы хранятся в приватной файловой системе, метаданные — в MySQL; S3 не требуется текущей поставке |
| ADR-012 | PUML и рендеры этапа 1 версионируются как проектная история; актуальная архитектура и миграции имеют приоритет при сверке реализации |
| ADR-013 | UX/UI: HTML/CSS/JS-прототипы и рабочие приложения; Figma исключена |
| ADR-014 | Целостный проверенный выпуск из `main`; новые миграции сохраняют пользовательские данные и прежние контрольные суммы |
| ADR-015 | Зашифрованная офлайн-очередь и вложения переживают перезапуск; нативный транспорт Bearer без Cookie/Origin |
| ADR-016 | Отчеты публикуются неизменяемыми версиями; заказчик не видит черновик и внутренние сведения |
| ADR-017 | Техническое хранение три года с отдельными точками отсчета категорий; действующие данные и незавершенные процессы сохраняются |
| ADR-018 | Зашифрованные копии БД/файлов и контролируемое восстановление; production-cron, отдельное хранение и измеренные RPO/RTO требуют финального протокола |
| ADR-019 | По рабочему уточнению доставка уведомлений, включая in-app, и внешние интеграции исключены; договорное изменение действует после подписания допсоглашения № 3 |
