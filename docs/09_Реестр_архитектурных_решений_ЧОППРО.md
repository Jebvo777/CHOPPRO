# Реестр архитектурных решений ЧОППРО

ADR-001: Backend - PHP 8.3+.

ADR-002: Основное транзакционное хранилище - MySQL 8/InnoDB.

ADR-003: Мобильный контур - отдельные приложения Android и iOS.

ADR-004: Архитектура MVP - модульный монолит.

ADR-005: Клиентский интерфейс - REST JSON `/api/v1`.

ADR-006: Tenant определяется сервером из доверенной сессии.

ADR-007: RBAC проверяет atomic permissions, а не имя роли.

ADR-008: Повторяемые мобильные операции идемпотентны.

ADR-009: Исходные события attendance/обходов сохраняются, override создается отдельно.

ADR-010: Redis - вспомогательная инфраструктура, источник истины - MySQL.

ADR-011: Бинарные файлы хранятся в S3, MySQL содержит метаданные.

ADR-012: Архитектурные диаграммы хранятся как PUML и версионируются вместе с кодом.
