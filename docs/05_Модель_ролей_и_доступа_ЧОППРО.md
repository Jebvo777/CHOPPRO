# Модель ролей и доступа ЧОППРО

Разрешение операции определяется tenant пользователя, permission роли, object scope и бизнес-ограничениями операции.

Роли MVP: Platform Super Admin, владелец/директор ЧОП, администратор ЧОП, операционный руководитель, начальник объекта, кадровик, ответственный за compliance, бухгалтер, охранник, представитель заказчика, аудитор read-only.

Проверка выполняется по atomic permissions вида `employees.read`, `employees.manage`, `facilities.read`, `facilities.manage`, `shifts.manage`, `reports.read`, `audit.read`, `roles.manage`.

Каждый запрос к tenant-данным применяет server-side tenant context. Прямой UUID другого tenant не дает доступа. Назначения ролей могут иметь object scope и срок действия.
