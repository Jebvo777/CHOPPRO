## Назначение сборок

Android APK: пакет `ru.choppro.guard`, версия `3.0.2`, код `30002`, minSdk 24, targetSdk 36. Сборка предназначена для тестирования и имеет тестовую подпись. Проверка в Android Emulator выполнена; production-ключ и полный полевой прогон еще требуются.

iOS: `CHOPPRO.app`, идентификатор `ru.choppro.guard`, версия `3.0.2`, build `1`, минимальная версия 16.4, платформа `iPhoneSimulator`. Это приложение запускается в Simulator на Mac; подписанного IPA для физического iPhone в переданном комплекте нет. Release-сборка и XCTest выполнены в CI.

Исходники мобильного проекта находятся в [`mobile/`](../mobile/README.md). Сборки выполняются workflow `mobile.yml`: Node 22, Android — JDK 17 / Gradle, iOS — macOS / Xcode / CocoaPods. Ключи подписи, профили и аккаунты магазинов в репозиторий не добавляются.
