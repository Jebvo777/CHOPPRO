# Статус GitHub и поставки Этапа 1

## 1. Репозиторий

GitHub: https://github.com/Jebvo777/CHOPPRO

Единственная рабочая ветка: `main`. Изменения `develop`, `portal/github-auto-sync` и `upload-signed-documents-20261002` объединены в `main`; история коммитов сохранена. Отдельная интеграционная ветка не используется.

## 2. Состав репозитория

В репозитории размещены backend-каркас PHP, MySQL migrations, Docker-конфигурация, CI workflows, web-каркасы, структура мобильных приложений Android/iOS, прототипы, документация, OpenAPI, PUML-диаграммы с SVG/PNG и материалы приемки Этапа 1. Портал в `acceptance-portal` автоматически получает содержимое и разделы из `main`, проверяя целостность файлов по Git blob SHA.

Части незавершенной загрузки подписанного отчета сохранены в `.signed-upload/report.part002`–`report.part011`. Первая часть отсутствует, готового PDF в этой загрузке нет; эти фрагменты не считаются подписанным документом поставки.

## 3. Проверки

PHP-файлы проходят синтаксическую проверку. Для backend-каркаса предусмотрен smoke-тест. CI проверяет синхронизацию портала, целостность кэша, переключение на основную ветку, настоящее подключение GitHub и работу страниц в браузере. Архив портала собирается из проверяемого коммита. Изменения PUML автоматически обновляют SVG/PNG и индекс SHA исходников.

## 4. Актуализация на Этапе 2

По мере реализации Core MVP в репозитории синхронно обновляются исходный код, OpenAPI и миграции базы данных. Проектная документация актуализируется в части, необходимой для соответствия фактически реализованному функционалу.
